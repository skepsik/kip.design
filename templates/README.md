# Wiki templates

Шаблоны — **каркас** для новых страниц. Канон живёт в `content/`.

| Файл | Когда |
|------|--------|
| [template-page.md](./template-page.md) | Любая design-страница |

Эталон объёма — соседние страницы в `content/` того же проекта.

---

## Новая страница

1. Скопировать [template-page.md](./template-page.md), убрать лишние §.
2. Имена — **как в коде**; design-only — пометка «(цель)».
3. Добавить ссылку в sidebar (`.vitepress/config.ts`).

---

## Язык (рекомендация)

- Prose — русский, если нет причины иначе.
- Идентификаторы кода — как в репозитории: `` `runTurn` ``, `` `omit` ``.
- EN compound-термины — блоком, не по словам: *failure-driven fallback*.
- Списки — обычные `- пункт` (VitePress не рендерит `- [ ]` как task list).

Стиль §-заголовков и lifecycle с issues — **на усмотрение проекта**; в kit только каркас.
